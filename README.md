# CaveDevz — Portfolio

Sitio portafolio de CaveDevz, servido en [cavedevz.com](https://cavedevz.com) vía GitHub Pages.

Sitio estático (HTML/CSS/JS puro, sin build step). Para editar:

- `index.html` — estructura y contenido (proyectos, bio, contacto).
- `css/style.css` — estilos (tema dark, un solo archivo).
- `js/main.js` — menú móvil, año del footer, animaciones de scroll.
- `assets/favicon.svg` — logo/favicon.

## Desarrollo local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```
npx serve .
```

## Deploy

Este repo se publica automáticamente vía GitHub Pages (Settings → Pages → Source: `main` / root).
El dominio personalizado está fijado en el archivo `CNAME`.
